THE HOUSE RULES, PRACTICALLY SPEAKING

Small tools.
Zero ceremony.

Whimfate is for the small crossroads where a coin, a wheel, or a silly question can help everyone get moving again.

Make the next step obvious.

When someone opens a randomizer, they should be able to do the thing in seconds. The input should be clear, the action should say what it does, and the result should be easy to read. No tutorial quest before a coin toss.

Keep the stakes in perspective.

Randomness is a great tie-breaker for dinner, game night, team lists, turn order, and other everyday standoffs. It is not an oracle for health, money, relationships, or anything that deserves actual care and judgment.

Make it fun, not fussy.

We can give a result a little theatre: a satisfying reveal, a bright accent, something worth sharing with a group chat. But the interface should stay quiet until the fun part happens. The orb can be dramatic so the buttons don't have to be.

Respect people's time and data.

Simple tools should not need accounts. Where a task can happen in the browser, that's the direction we prefer. Any analytics, advertising, or data handling will be described according to what is actually deployed, not what sounds nice in a footer.

Be honest about what is ready.

Planned features should look planned, not pretend to work. As each game launches, it should do one job well before we add extra settings, modes, or cosmic accessories.

Less deciding how to use the tool. More using the tool.

That's our way: useful first, funny second, mysterious only where it helps.

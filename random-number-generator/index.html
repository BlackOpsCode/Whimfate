A SMALL TOOL FOR BIG DECISIONS

A random number generator that keeps it simple.

Use Whimfate's free random number generator for raffles, classroom picks, games, tabletop tables, number draws, quick probability exercises, or the moment a group needs an impartial number. Set an inclusive minimum and maximum, choose how many integers to draw, and decide whether repeated numbers are allowed.

When the browser supports the Web Crypto API, the generator draws from browser cryptographic randomness and uses rejection sampling so modulo bias does not skew the results. The animation happens only after the final numbers are chosen: the visual drama does not decide the outcome. If you turn off repeats, the tool selects distinct numbers from the chosen range and checks that enough unique values exist before drawing.

Your inputs and results stay in the page while you use it. There is no account, no upload, and no server-side list of numbers. Share the text, send the number-card image on compatible devices, or download the PNG for a group chat or game session.

THE QUESTIONS BEFORE THE DRAW

Random number FAQ

How does Whimfate pick random numbers?

Where available, it uses the browser's Web Crypto API and rejection sampling to avoid modulo bias. The final values are selected before the animation begins, so the animation cannot change the result.

Are the minimum and maximum included?

Yes. Both limits are inclusive. A draw from 1 to 10 can return 1 or 10.

Can I draw numbers without repeats?

Yes. Switch off Allow repeats. The generator checks that your requested quantity fits inside the range and then draws distinct integers without replacement.

Can I use negative numbers or large ranges?

Yes. Any safe integer can be used as a minimum or maximum, including negative values. Equal endpoints are valid when they match the number of requested unique results.

Can I share the result as an image?

Use Share picture on a browser/device that supports direct file sharing. If it does not, choose Download image and attach the PNG to your message manually.
